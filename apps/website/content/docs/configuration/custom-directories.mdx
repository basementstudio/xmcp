Customize where `xmcp` looks for tools, prompts, resources, and skills by configuring the `paths` option. If not specified, these are the defaults:

```typescript title="xmcp.config.ts"
const config: XmcpConfig = {
  paths: {
    tools: "src/tools",
    prompts: "src/prompts",
    resources: "src/resources",
    skills: true,
  },
};

export default config;
```

## Disabling directories

To disable a specific directory, set it to `false`:

```typescript title="xmcp.config.ts"
const config: XmcpConfig = {
  paths: {
    tools: "src/tools",
    prompts: false, // Prompts directory disabled
    resources: "src/resources",
  },
};

export default config;
```

## Skills directory

The [skills](/docs/core-concepts/skills) directory is optional. With the default, `skills: true`, `xmcp` reads `src/skills` when it exists: every directory there with a `SKILL.md` is served as a skill, and any other file or directory is skipped with a warning. A project without a `src/skills` directory builds as usual and serves no skills.

Setting `skills` to a path, including `"src/skills"`, makes the directory required: it has to exist, and the build fails for any entry in it that is not a valid skill. Set `skills` to `false` to ignore the directory.

## Troubleshooting

If you delete the tools, prompts, or resources directory without updating the config, `xmcp` will throw an error and prompt you to update it.
