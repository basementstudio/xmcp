Customize where `xmcp` looks for tools, prompts, resources, and skills by configuring the `paths` option. If not specified, these are the defaults:

```typescript title="xmcp.config.ts"
const config: XmcpConfig = {
  paths: {
    tools: "src/tools",
    prompts: "src/prompts",
    resources: "src/resources",
    skills: "src/skills",
  },
};

export default config;
```

## Disabling directories

To disable a specific directory, set it to `false`:

```typescript title="xmcp.config.ts"
const config: XmcpConfig = {
  paths: {
    tools: "src/tools",
    prompts: false, // Prompts directory disabled
    resources: "src/resources",
  },
};

export default config;
```

## Skills directory

The [skills](/docs/core-concepts/skills) directory is optional. With the default path, a project without a `src/skills` directory builds as usual and serves no skills. Set `skills` to a custom path to read skills from there, in which case the directory has to exist, or to `false` to ignore the directory.

## Troubleshooting

If you delete the tools, prompts, or resources directory without updating the config, `xmcp` will throw an error and prompt you to update it.
