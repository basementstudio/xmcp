## Getting started

### Connect to a client

<McpConnect serverName="xmcp-docs" serverUrl="https://xmcp.dev/mcp" />

Click any card to copy the connection config for your client.

### Standard connection

For clients not listed above, you can use the following connection method.

```json
{
  "command": "npx",
  "args": ["mcp-remote", "https://xmcp.dev/mcp"]
}
```

## Available tools

The server exposes three read-only tools that agents use automatically:

| Tool         | Use it to                                                         |
| ------------ | ----------------------------------------------------------------- |
| `search`     | Find pages that answer a question                                 |
| `list-pages` | Browse every page by section, with its id, title, and description |
| `get-page`   | Read one page as markdown by its id                               |

Page ids look like `configuration/transports`. `search` also accepts an `id` and returns that page, so existing setups keep working.

The server describes itself at [`/.well-known/mcp/server-card.json`](https://xmcp.dev/.well-known/mcp/server-card.json), so discovery tools can find the endpoint from the domain.

## Example usage

Once connected, just ask your agent about xmcp:

- "How do I configure xmcp for Next.js?"
- "What transport options does xmcp support?"
- "How do I create a tool with authentication?"

The agent will search the docs and provide accurate answers with code examples.

## Troubleshooting

- **Not connecting**: Verify the URL `https://xmcp.dev/mcp` is correct and restart your agent
- **No results**: Try more specific queries, or call `list-pages` to find the exact page id
- **Agent not using MCP**: Check your agent's MCP configuration and logs
