Upscale and enhance images with Topaz Labs' standard and generative models. Start with the [runnable example](https://github.com/basementstudio/xmcp/tree/main/examples/topaz-http).

## Configure access

Create an API key in your [Topaz account](https://www.topazlabs.com/api). The API needs an active developer subscription and credits; there is no free tier. Jobs are billed by output megapixels. Service-side failures are refunded.

```bash
TOPAZ_API_KEY=your-provider-credential
MCP_API_KEY=your-separate-client-secret
```

MCP clients send `MCP_API_KEY` as `x-api-key` on every request, compared in constant time. The server is stateless: it keeps no sessions and no job records. The server sends the source image's URL to `https://api.topazlabs.com/image/v1` with the `X-API-Key` header, so Topaz downloads the image itself. Submissions are never retried. All authorized MCP clients share the same provider account and its credits, and any of them can read a job whose ID they have.

## Available tools

| Tool                 | Purpose                                                                                      |
| -------------------- | -------------------------------------------------------------------------------------------- |
| `upscale-image`      | Upscale an image from a public https URL. Set `generative: true` for models that add detail. |
| `get-upscale-job`    | Wait for a job and return the result with a fresh one-hour link, or its progress.            |
| `cancel-upscale-job` | Cancel a job that has not finished.                                                          |

## Results

Generation runs as a provider job. Each call answers within about 50 seconds, counted from when the tool starts, and sends MCP progress notifications while it polls. When the job finishes, the result contains the image inline and a JSON summary with the provider link and its expiry. Longer jobs return their `jobId` instead; call `get-upscale-job` with it to keep waiting. If the provider stops responding after a submission, the tool still returns the `jobId`. Cancelling the MCP request stops waiting but does not cancel the provider job. Images larger than 8 MB come back as a link only. Topaz download links expire one hour after they are issued. Call `get-upscale-job` again for a fresh one; results are kept for seven days.

Pass a Topaz model name in `model`, for example `"High Fidelity V2"`, or leave it out for Topaz's default. Check the names in Topaz's model playground, because the documented lists differ. A finished job is charged in full even if you cancel it.

## Run the example

Follow the [example README](https://github.com/basementstudio/xmcp/tree/main/examples/topaz-http#run-locally) for installation and startup. Its tests replace every provider request with a local fake, so they need no credentials.
