# @xmcp-dev/compiler

Development-only compiler for [`xmcp`](https://www.npmjs.com/package/xmcp).

Install it alongside the matching runtime version:

```bash
npm install xmcp zod
npm install --save-dev @xmcp-dev/compiler
```

Keep using the `xmcp dev`, `xmcp build`, and `xmcp create` commands from your
project scripts. The `xmcp` package forwards those commands to this compiler.
